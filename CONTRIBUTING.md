# Contributing to FlutterScene 3D

First off, thank you for considering contributing to FlutterScene 3D! It's people like you that make this project a great tool for the community.

## Code of Conduct

By participating in this project, you are expected to uphold our Code of Conduct.

## How Can I Contribute?

### Reporting Bugs

- Check the [Issues tab](https://github.com/ArbazKhan1645/flutter_scene_3d/issues) to see if the bug has already been reported.
- If not, open a new issue. Use a clear title and provide as much detail as possible (logs, screenshots, device info).

### Suggesting Enhancements

- Open a new issue with the tag "enhancement".
- Explain why this feature would be useful and how it should work.

### Pull Requests

1. Fork the repo and create your branch from `main`.
2. If you've added code that should be tested, add tests.
3. Ensure the test suite passes.
4. Make sure your code lints.
5. Issue that pull request!

## Styleguide

- We follow the [official Dart style guide](https://dart.dev/guides/language/analysis-options).
- Use `dart format` before committing.
- Follow the feature-first modular architecture.

## Questions?

Feel free to open an issue for any questions you might have!
