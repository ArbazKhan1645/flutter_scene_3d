# Security Policy

## Supported Versions

The following versions of FlutterScene 3D are currently being supported with security updates:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0.0 | :x:                |

## Reporting a Vulnerability

We take security seriously. If you discover any security-related issues, please do not open a public issue. Instead, please report it privately.

Please email [mashwanikhan192@gmail.com](mailto:mashwanikhan192@gmail.com) with the details of the vulnerability. We will acknowledge your email within 48 hours and provide a timeline for a fix.
